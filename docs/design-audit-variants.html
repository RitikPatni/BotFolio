4. Control Icons — Emoji → SVG

CURRENT — Emoji glyphs
⌨ Studio (keyboard)
📷 Field (camera)
◐ Theme
OS-dependent rendering — monochrome on Linux, color emoji on macOS. ◐ scales poorly.
PROPOSED — SVG icons (Lucide style)
Studio (braces)
Field (aperture)
Theme (contrast)
